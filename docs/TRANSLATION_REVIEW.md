The Korean, Chinese (Traditional and Simplified), Armenian, Tagalog and Farsi UI text was machine-made by an AI model and has not been reviewed by a native speaker. The app labels each of these languages "Beta translation" for that reason.

A wrong word in these strings could change a life-safety answer (fire separation, escape windows, smoke and CO alarms, sprinklers, burn areas, engineering). Each one needs a native speaker who also knows building terms to confirm it before the beta label can come off. This file is generated by `node scripts/translation-review.mjs` with the same pattern the test uses (`app/src/test/r9/i18n.test.ts`); the test fails if a safety string is missing here.

How to review: read the English, read the translation, then either confirm it or fix it in `app/src/ui/locales/<code>.json` and put your name in that file's `_meta.reviewedBy` once every row for that language is done. See `docs/TRANSLATING.md`.
