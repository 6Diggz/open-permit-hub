# Privacy notes (facts, not a privacy policy)

These are engineering facts for the attorney who will write the privacy notice (`TERMS_PENDING_ATTORNEY_REVIEW.md`). They are not legal advice and not a legal notice.

- **No server of ours.** The app is static files on GitHub Pages. It has no accounts, no analytics, no telemetry and no error upload.
- **Project data stays in the browser** (IndexedDB database `opa-store`, keys `opa.index` and `opa.p.<id>`; older versions used `localStorage` with the same keys, and the app moves them on first start). It leaves the device only when the user saves or shares a file.
- **Network requests**: to the site's own origin, plus the two City of LA map hosts (`maps.lacity.org`, `zimas.lacity.org`) and two regional transit map hosts (`services.arcgis.com` for LA County Planning's High Quality Transit Area layer, `rdp.scag.ca.gov` for SCAG's Transit Priority Areas) only when the user taps Look up (see Parcel lookup below). The Content-Security-Policy `connect-src` lists exactly these: `'self'`, `blob:`, `data:`, `https://maps.lacity.org`, `https://zimas.lacity.org`, `https://services.arcgis.com`, `https://rdp.scag.ca.gov`. Checked in CI by `app/e2e/e2e.mjs` (test "appsec-12").
- **Site-visit photos** (inspector field mode) are compressed on the phone and kept in the browser's IndexedDB, not in the project record. They leave the device only inside a site-visit `.permitpack` or the visit PDF that the user saves or shares, and in the handoff ZIP's `site-visit.pdf`.
- **Parcel lookup** sends the typed address to the City of LA's public map services (`maps.lacity.org`, `zimas.lacity.org`) only when the user taps Look up. For the half-mile transit question it then sends the lot's map outline (coordinates only, no address) to the LA County and SCAG transit maps.
- **Error reports** are built on the device and copied by the user; they hold app version, rule pack, error text and stack, no project data (`app/src/core/errorreport.ts`).
- **GitHub** hosts the site and sees visitor IP addresses under its own terms.
- **CCPA/CPRA**: the published thresholds (for example, annual revenue above about $26.6M, or buying/selling/sharing personal information of 100,000+ consumers) are far from this project today, and the app collects no personal information on a server. Whether the law applies is a legal question: **attorney to confirm**. Re-check before adding accounts, analytics, payments or any server.
