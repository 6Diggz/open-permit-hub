# Contributing
- Sign off each commit (`git commit -s`), per the Developer Certificate of Origin.
- New or changed rules need: a citation with a link, an effective date, and a pass test plus a fail test in `app/src/test`.
- Rule text is written in your own words. Never paste copyrighted code text.
- No GPL code in the app bundle (CI checks this).
- AI-assisted changes are welcome; add an `Assisted-by:` line. A human signs off.
